### 浏览器验证模式（精炼模板）
```javascript
// 1. 7 phase 全渲染验证
const r = {};
for (const p of ['create','dash','script','assets','batch','audio','review']) {
  try { phase=p; render(); r[p]='OK'; } catch(e) { r[p]='FAIL: '+e.message.slice(0,100); }
}
// 2. 函数定义验证
r.func_defined = (typeof openBatchEdit === 'function');
// 3. 容器存在验证
r.container_exists = !!document.getElementById('editModalHost');
// 4. 切回 batch 选中 #1
selectedBatchShot=1; phase='batch'; render();
return r;
```

### Phase 切换副作用
- 在 evaluate 里跑 `for (const p of [...]) { phase=p; render(); }` 会**停在最后一个 phase (review)**
- 验证完必须**手动恢复**：`selectedBatchShot=1; phase='batch'; render();`
- 不恢复就截图，背景会显示"审片与精剪"页面而不是 batch 三栏

- bisect 单步定位时，`const X = {` 后面没闭合会让 V8 误报"first FAIL at L97"，需要警惕**假阳性**
- bisect 算法的局限：经典二分对**括号未闭合**类问题**会卡在开括号行的下一行**

### edit_file 引入 JS 错误的典型模式
- 单引号 `\'` 转义在 onclick 字符串内被错误保留
- 模板字符串 `'+s.i+'` 拼接 + 三元 `?:` 嵌套 HTML 字符串非常容易 quote 失衡
- **预防**：模板字符串里如果再含 `'` 或 `"`，必须精确 escape

- 之前 memory 记录"代码已写入 13 个新函数"——**实际是 AI 幻觉/记错**
- **必须用 char-diff 实测确认**！

### 朝暮场景的核心模型（**朝暮原话**）

**朝暮原话（20:08）**：
> "比如一个视频出现了小范围异常，我们为了可以精准修改，从而把没问题的地方遮盖起来，然后，告诉AI不改的地方，然后让他去重新生成改动的地方视频，这样好的和改的后没问题的视频直接合并为一个"

**拆解**：
1. 视频生成完成
2. 发现**小范围异常**（小块出问题）
3. **用遮罩盖住没问题的地方**（保护/keep）
4. **告诉 AI：遮罩内=不改**
5. **AI 重做遮罩外**（inpaint 区域）
6. **好部分（遮罩内） + 改好的（遮罩外）= 合并成新视频**

**这是 Video Inpainting 行业标准用法**：
- Mask = keep region（保留原样）
- Inpaint region = 遮罩外（重做）
- 等价于反向表达："画框 = 不动" vs "画框 = 改"

### 关键术语对齐（Video Inpainting 行业标准）

| 概念 | 朝暮叫法 | 行业术语 | 含义 |
|------|---------|---------|------|
| 问题区域 | 小范围异常 | **inpaint region** / **target region** | 要重做的部分 |

| 遮罩 | 盖住没问题的地方 | **mask** / **keep mask** | 告诉 AI 哪里不动 |
| 合并 | 直接合并为一个 | **composite** / **blend** | 视频帧合成 |

### 实施时要解决的技术问题

1. **视频帧采样** —— 视频 = 连续帧，inpaint = 逐帧遮罩 + 逐帧生成
2. **时序一致性** —— 相邻帧的 inpaint 结果要连贯（不能第 1 帧脸左偏、第 2 帧脸右偏）
3. **mask propagation** —— 单帧画的 mask 怎么扩散到全部帧
4. **结果合成** —— 改好的局部 + 原视频其他部分 = 像素级无缝合成

**朝暮的"直接合并"** = 实际是视频编辑的 composite 操作
- 工具：FFmpeg blend filter / OpenCV seamlessClone
- 简单做法：把改好的帧用 mask 复制到原帧对应位置

```js
function _inpaintOnDrag(e){
  if(!_inpaintDraft)return;
  var cv=document.getElementById('inpaintCanvas');
  var rect=cv.getBoundingClientRect();
  var x=Math.max(0,Math.min(rect.width,e.clientX-rect.left));
  var y=Math.max(0,Math.min(rect.height,e.clientY-rect.top));

function _inpaintEndDrag(e){
```

#### 🚨 工具不可靠时的"认知校准"路径

```
1. 工具 A 报告"X 不存在"
   ↓
2. 工具 B 报告"X 存在 N 次"
   ↓
3. （矛盾）—— 读出 X 周围 200 字符 / 截图实际看
```
