# 第 3 章 6 大生产级要求逐项满足方案

## 3.1 稳定 (Reliability)

**6 大稳定保障**:

1. **9 状态机 + 选择性重试** — 单环节失败不传染
2. **错误日志 + 派单** — failed 自动派单到对应 Agent 重做
3. **异步任务队列** — 长时间任务不阻塞 UI
4. **多供应商路由** — Runway 失败自动切 Veo 3.1
5. **数据快照 + 回滚** — 任何状态可回退到上一稳定点
6. **健康检查 + 告警** — 任务卡死 5 分钟自动告警

**KPI**: 系统可用性 99.9% (≤8.76 小时/年停机)

## 3.2 高效 (Efficiency)

**3 大效率提升**:

1. **批量生成** — 24 镜头/集 一次性入队, 4 镜头并行
2. **缓存复用** — 5 资产层 ref 一次生成, 全剧复用
3. **OPC 统计** — 1 人 1 周 60s 短剧的人效目标

**KPI**:
- 单镜头生成 ≤ 30s
- 24 镜头/集 ≤ 12 分钟
- 单部 60s 短剧 ≤ 5 天 (1 人)

## 3.3 质量好 (Quality)

**5 大质量保障**:

1. **18 维质检体系** — 对齐 VBench-2.0
2. **IP-Adapter FaceID v2** — 跨镜头 0 漂移
3. **5 资产层 ref 打包** — 自动注入关键帧
4. **阈值 0.70-0.85** — 略上调避免过度打回
5. **3 种处理** — ≥85 通过 / 75-84 警告+遮罩 / <75 打回

**KPI**: 一次通过率 95% / 角色脸锁 99% / 质检综合分 88+ 分

## 3.4 流程清晰 (Process)

**6 步 SOP 标准化**:

```
Step 1: 项目创建 (🎩总控)
```

# 第 4 章 6 大核心模块设计

## 模块 1: 剧本分析引擎 (编剧 Agent)

**功能**: 小说 → 标准剧本 → 镜头列表

**输入**: TXT/DOCX/PDF 小说文本  
**输出**: 标准剧本 JSON + 镜头列表 JSON

**关键算法**:
- 多格式解析 (TXT/DOCX/PDF)
- 角色提取 (GPT-4o NER)
- 场景识别 (章节 + 关键词)
- 镜头拆解 (动作+对话+时间)
- 节奏控制 (目标时长 → 镜头密度)

**API 选型**: GPT-4o (主) / Claude-3.5 (长文) / Qwen-Plus (本地)

## 模块 2: 5 资产层自动化 (资产 Agent)

**功能**: 实体清单 → 资产图库 (角色/场景/道具/服装/声音)

**输入**: 实体清单 JSON  
**输出**: 5 资产层 ref 图 + 嵌入向量

**关键算法**:
- 角色 6 层身份锚点 (面部/体型/发型/服装/配饰/声音)
- 场景多视角生成 (主视图 + 空间参考 + 光照参考)
- 道具参考图 (GroundingDINO 检测)
- 衣橱变体 (IP-Adapter Clothing)
- 音色嵌入 (ElevenLabs 提取)

## 模块 3: 18 维质检引擎 (质检 Agent)

**功能**: 成片 → 18 维评分 → 质检报告

**输入**: 视频文件 + 关键帧 + 资产库  
**输出**: 18 维 JSON 报告 + 派单指令

**关键算法**:
- 主体一致性 (DINOv2 + ArcFace)
- 美学质量 (LAION Aesthetic)
- 跨镜头 (CLIP ViT-L/14)
- 时间连贯 (RAFT)
- 物体永存 (Track Anything)
- 阈值判定 (3 档: 通过/警告/打回)

## 模块 4: 关键帧驱动 (分镜 Agent)

**功能**: 镜头列表 → 关键帧图 (首帧 + 尾帧)

**输入**: 镜头列表 + 5 资产层 ref + 项目风格预设  
**输出**: 关键帧 PNG

**关键技术**: 
- IP-Adapter FaceID v2 (角色脸锁)
- ControlNet Depth (场景)
- ControlNet OpenPose (动作)
- 5 资产层 ref 自动打包注入

## 模块 5: 视频生成编排 (视频 Agent)

**功能**: 关键帧 → 视频片段

**输入**: 关键帧 + 镜头描述 + 运镜指令  
**输出**: 视频片段 MP4

**关键技术**:
- 主选 Runway Gen-4 (角色锁 + Aleph 一致性)
- 备选 Veo 3.1 (首尾帧插值)
- 草稿用 Veo, 终稿用 Gen-4 (成本控制)

## 模块 6: OPC 自动化与人效统计

**功能**: 1 人 1 周 60s 短剧的工时统计

**输入**: 全流程任务日志  
**输出**: OPC 统计面板

**核心指标**:
- 各 Agent 工时占比
- 一次通过率
- 单镜头平均重试
- OPC 系数 (1.0 = 达标)
