### 模块 3: IP-Adapter 显式调用接口 (P0-1)
**功能**: 在分镜关键帧生成时, 显式调用 IP-Adapter FaceID v2

```typescript
// 关键帧生成 API (V5 已有骨架)
async generateKeyframe(shotId: string) {
  const shot = SHOTS[shotId]
  const refs = shot.references  // P0-2 自动化产出
  
  // P0-1: 显式调用 IP-Adapter FaceID v2
  const faceidRef = refs.character_references[0] // 选正面
  
  const prompt = buildShotPrompt(shot)
  
  // FLUX + IP-Adapter 多 ref
  const image = await flux.generate({
    prompt,
    ip_adapter: {
      faceid_v2: faceidRef,    // 角色脸锁 (P0-1)
      clothing: refs.wardrobe, // 服装锁 (P1-3)
      style: refs.style,       // 风格锁
    },
    controlnet: {
      depth: refs.scene_depth,  // 场景深度 (P1-1)
      openpose: refs.pose,       // 动作姿态 (P1-2)
    },
    quality_boost: {
      aesthetic: 0.85,  // 美学评分 (P0-4)
      imaging: 0.80,    // 成像质量 (P0-4)
    }
  })
  
  return image
}
```

## 五、关键技术决策 (5 大)

### 决策 1: 一致性技术选型 = IP-Adapter + ControlNet 组合
- **主选 IP-Adapter v2 + FaceID v2**: 业界 2025 SOTA, 10 个方案中 8 个基于它
- **辅选 ControlNet**: Depth (场景) + OpenPose (动作) + Color (色调)
- **不选 DreamBooth/Textual Inversion**: 需要训练, 周期长, 不适合快速生产

### 决策 2: 视频模型选型 = Runway Gen-4 (主) + Veo 3.1 (备)
- **Runway Gen-4**: 角色锁最强, Aleph 一致性, 主选
- **Veo 3.1**: 首尾帧插值成熟, 备选
- **Sora 2 / Seedance 1.0 Pro**: P2 远期接入 (高质量但成本高)

### 决策 3: 质检阈值 = 0.6-0.85 (对齐 VBench 0.6-0.95)
- **整体阈值** 0.65-0.85 → 0.70-0.85 (略上调, 避免过度打回)
- **单维度阈值**:
  - 主体一致性 ≥ 0.85 (严格)
  - 服装/背景 ≥ 0.80 (中等)
  - 角色动作 ≥ 0.80 (P1-5 上调)
  - 美学/成像 ≥ 0.65 (P0-4 新增, 宽松)
  - 表情/手部 ≥ 0.70 (P1-4 新增, 中等)
- **综合分 ≥ 85 分**: 通过
- **综合分 75-84**: 警告 + 遮罩修
- **综合分 < 75**: 打回 + 整段重跑

### 决策 4: 资产存储 = MinIO (本地) + OSS (云端)
- **MinIO**: 本地开发, Docker 部署, 零成本
- **OSS**: 生产环境, 多副本, 全球 CDN
- **向量索引**: pgvector (PostgreSQL 扩展) 存角色/场景/道具 CLIP 特征
- **关系数据**: PostgreSQL + JSONB (适配 SHOTS/CHARS/SCENES 复杂结构)

### 决策 5: 部署 = Docker Compose (小) → K8s (大)
- **小规模** (1-5 人团队): Docker Compose, 单机 3080Ti 足够
- **中规模** (5-20 人): K8s + GPU Node Pool
- **大规模** (20+ 人): K8s + 多区域 + CDN
